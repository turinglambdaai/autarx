# Autarx 使用指南

[English](USER-GUIDE.md) · **简体中文**

在实施经审阅的变更前，检查、比较并追踪 AUTOSAR 交付数据。

## 当前可用状态

工程预览；完整官方工作台规划为买断，目前尚未开放付费购买。

## 平台与安装

提供 macOS、Windows、Linux Rivet 桌面预览；CLI 和 MCP 共用 Racket 领域核心。AUTOSAR 支持范围由产品契约规定，不代表支持所有 ARXML。

从[官方 Releases](https://github.com/turlamai/autarx/releases)选择明确标注系统和架构的附件，阅读该版本说明并核对附带校验文件。未列出的附件或平台不视为已交付。预览构建可能没有系统发行者签名或公证；不要为安装而关闭系统安全保护。

## 第一次使用

1. 先打开合成 OemDelivery 夹具，再处理机密交付件。
2. 检查未解析引用，对比两个副本，阅读影响分析；unknown 和歧义结果需要继续核查。
3. 需要修改时，先生成 patch plan 和语义差异，审阅后仅在可丢弃的工作区副本中应用。

## 数据、备份与恢复

保留不可变的原始交付件。工作区、.autarx 备份及审计和 patch 历史一起备份。工具差异结果用于工程审阅，不等于供应商验证或安全认证。

## 联网、密钥与隐私

检查和追踪处理本地交付文件。诊断可能暴露主机厂、供应商名称、路径和配置；授予外部工具或 agent 工作区权限前应先审查。

## 已知限制

大型交付件性能预算和完整支持范围验收仍待完成（#22）。历史 .NET 发行版不是当前 Rivet 实现。

## 更新与卸载

先备份数据，再阅读目标版本说明。应用内检查更新不一定能安装当前渠道的更新；按手册区分便携包、系统安装器和源码安装。不要绕过失败的验签或用来源不明的文件覆盖程序。更新失败时保留现有数据与错误信息，使用可信发行包恢复；卸载程序通常不等于删除独立的数据目录，删除个人数据前先确认备份。

## 获得帮助

在 [GitHub Issues](https://github.com/turlamai/autarx/issues) 反馈，中文或英文均可。提供版本、系统与架构、安装渠道、复现步骤、预期和实际结果。先用合成样本复现；不要附上密钥、授权文件、数据库、原始私密文档或完整日志。公开支持不承诺响应时限。
