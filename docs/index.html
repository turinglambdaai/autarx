What it does

The delivery gap, closed in one window.

Open ARXML directly

System Description, System Extract, ECU Extract, ECUC and communication ARXML — multi-file delivery packages, no vendor configurator required.

Workspace semantic index

Every SHORT-NAME becomes an indexable object with source-file provenance and a cross-file reference graph.

Delivery inspection

One inspect command answers the first question of every delivery: package inventory, ECU list, network inventory, SWC and communication counts.

Find, refs, trace

Locate any signal, PDU, SWC or ECU element and follow its references across files — broken references reported, not hidden.

Validate before vendors

Structural ECUC validation (ARX001–ARX006) so the ARXML is sound before it reaches DaVinci, tresos or ISOLAR.

Agent-friendly CLI

The same workflows run from CLI and CI with stable JSON output — ready for automation and AI agents.

Platform contract

Not a configurator. A workbench.

Autarx does not replace DaVinci Configurator, EB tresos or ETAS ISOLAR. It closes the engineering gap between receiving an OEM delivery and opening the vendor toolchain.
